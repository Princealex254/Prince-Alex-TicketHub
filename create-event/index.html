Publishing checklist

  • Use a clear, well-lit poster - it is the first thing customers see.
  • State the venue and location exactly as attendees will search for it.
  • Keep the description practical: programme, gate times, what is included.
  • Sales end should be before or at the event start time.
  • Create at least one ticket type before submitting the event for approval.
  • Active submits the event to the platform team: it goes on sale once they approve it.
